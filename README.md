# notes

这是我的笔记仓库。

## 可以放什么

- 学习笔记
- 项目想法
- 日常记录
- 资料整理
- 有意思的工具
- 可复用的 skill

## 收藏区

- [工具库](tools/README.md)：记录好用、有趣、值得以后再试的工具。
- [Skill 库](skills/README.md)：记录 Codex skill、工作流、提示词套路和可复用能力。
- [工作流](workflows/agent-dev-loop.md)：记录用 agent 开发、测试和验收的固定流程。
- [项目区](projects/README.md)：记录具体项目的需求、任务、决策和 agent 开发流程。
- [灵感收件箱](inbox.md)：先把没整理完的东西丢进来，之后再归档。

## 记录建议

遇到一个东西时，不用一开始就写得很完整。先记三件事就够了：

1. 它是什么
2. 它能帮我做什么
3. 下次什么时候会想起它
