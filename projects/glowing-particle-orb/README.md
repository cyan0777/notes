# Glowing Particle Orb / Raster Aurora

光栅噪点与动态极光页面实验。当前版本是一个 NeuroRix 风格的 AI landing hero，用 Canvas 极光、grain 噪点和玻璃 UI 做光栅质感。

## 当前状态

- 偏网页 hero / 品牌视觉方向。
- 重点是背景光栅、噪点、动态极光和 AI 产品页氛围。
- 与 `electric-particle-orb` 分开维护，避免动效球实验影响页面类实验。

## 文件

- `index.html`：页面结构。
- `styles.css`：hero、导航、输入框和噪点样式。
- `aurora.js`：Canvas 极光动画。

## 预览

在本目录启动静态服务后打开 `index.html`。
