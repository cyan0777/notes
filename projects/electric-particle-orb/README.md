# Electric Particle Orb

动态发光粒子球实验。当前版本是 Canvas 实现，用中心发射粒子、液态焦散、外环吸收和辉光层模拟 AI 状态动效。

## 当前状态

- 固定粒子密度，避免实时调粒子数量造成卡顿。
- 控制项保留：形变、速度、辉光、暂停/继续。
- 视觉方向：白色高亮、轻微彩虹折射、玻璃液态涟漪、外圈吸收边界。

## 文件

- `index.html`：页面结构和控制面板。
- `styles.css`：全屏舞台和控制面板样式。
- `orb.js`：Canvas 动画主体。

python3 -m http.server 8765 --bind 127.0.0.1
